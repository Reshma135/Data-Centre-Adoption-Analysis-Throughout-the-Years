# DATA CENTRE ADOPTION ANALYSIS

## Project Overview

This project analyzes data centre adoption and growth across different countries, cities, and regions over the years. The analysis focuses on data centre growth, internet penetration, economic factors, electricity access, renewable energy usage, and regional patterns.

## Problem Statement

The project aims to understand how data centre adoption has changed over time and how factors such as internet penetration, economic conditions, electricity access, and regional differences are associated with data centre growth.

## Objectives

* Analyze data centre growth over the years.
* Compare data centre adoption across regions and cities.
* Study the relationship between data centre adoption and internet penetration.
* Analyze economic and infrastructure-related factors.
* Identify important business insights from the data.
* Build an interactive Power BI dashboard for visualization.

## Dataset

The dataset contains **20,000 records and 15 columns** covering information about countries, cities, regions, years, data centre counts, population, internet penetration, electricity access, renewable energy percentage, GDP per capita, risk index, and other factors.

## Tools & Technologies

* **Excel / WPS Sheets** – Data cleaning and pivot table analysis
* **SQL** – Data querying, cleaning, aggregation, and analysis
* **Python (Pandas)** – Data cleaning and exploratory data analysis
* **Power BI** – Interactive dashboard and data visualization
* **GitHub** – Project documentation and portfolio

## Data Cleaning

The dataset was reviewed and prepared before analysis. Data types, duplicate records, missing values, inconsistent values, and formatting issues were checked. Excel and Python were used for data cleaning and validation.

## SQL Analysis

SQL was used to work with the dataset and perform data analysis using:

* Data cleaning and validation
* Aggregations
* KPI calculations
* Grouping and filtering
* SQL views
* Window functions

## Python Analysis

Python with Pandas was used for:

* Data cleaning and validation
* Exploratory Data Analysis (EDA)
* Descriptive statistics
* Distribution analysis
* Outlier analysis
* Correlation analysis
* Segment analysis
* Trend analysis

## Power BI Dashboard

An interactive Power BI dashboard was created to present the analysis visually.

The dashboard includes:

* **Overview** – Key performance indicators and overall project summary
* **Trends** – Data centre trends across years
* **Segments** – Analysis by city, region, and electricity access

Interactive filters and slicers are included to allow users to explore the data.

## Key Insights

* Data centre adoption varies across countries, cities, and regions.
* Data centre growth can be examined alongside internet penetration and economic indicators.
* Infrastructure factors such as electricity access and renewable energy usage provide additional context for data centre adoption.
* Regional and city-level analysis helps identify differences in data centre distribution.

## Recommendations

* Focus on regions with strong digital infrastructure and growing internet adoption.
* Consider electricity availability and renewable energy potential when evaluating data centre expansion.
* Use regional and city-level insights to support data centre planning and investment decisions.
* Continue monitoring data centre growth trends over time.

## Limitations

* The analysis is based on the available dataset and its variables.
* The dataset may not represent every country or data centre globally.
* Observational relationships do not necessarily establish causation.
* Additional real-world factors may influence data centre adoption.

## Conclusion

This project provides a data-driven view of data centre adoption across years, regions, and cities. By combining Excel, SQL, Python, and Power BI, the project demonstrates a complete data analytics workflow from data preparation and analysis to interactive business visualization.
